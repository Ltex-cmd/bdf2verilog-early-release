Method and scope
Serial execution. Seven raw samples per case and mode. Fresh measurements use
new contexts, including source reads, parsing, hierarchy, connectivity, validation,
rendering and destruction. Two warmups per launch; calibrated batches target
40 ms with at most 1000 repetitions. Samples are per-conversion batch averages.
CLI timings include process launch and captured stdout plus Python subprocess
overhead, with two warmups and seven single-conversion trials. No output writes
are timed. The OS file cache is warm; retained converter contexts are not used.

No Quartus runs, synthesis, retained-cache benchmarks, cold-cache runs, hardware
resource estimates, or cross-platform performance tests were performed here.
The earlier native Quartus comparison is not part of these results. No speedup
over Quartus, another revision, or universal algorithmic bound is claimed.
The dense early-hit family uses scalar terminals on single-bit labeled buses;
wide vector terminals bypass contact classification and would miss that path.

Correctness limits
The Makefile run used repository synthetic tests; external corpus counts are zero.
The identity checks inspect literal generated assignments. They are not general
HDL equivalence proofs. Independent four-state identity testbenches are generated
for all cases, but were not simulated here because no HDL simulator is installed.
Broader vendor/LPM, sequential and external-corpus validation belongs in separate
evidence. Linux results do not establish macOS or Windows support.

Reproduce and integrate
Copy benchmarks/alpha into the checkout; no existing files need to be overwritten.
Read benchmarks/alpha/BENCHMARKS.md for exact commands and simulator checks.
Use the full commit above for this source. Raw samples, hashes, test log and
separate validation records are in benchmarks/alpha/evidence/linux-5e3cc48.
New timings from another host must retain that host platform/compiler metadata.
If only documentation changes, compare all validation_inputs_sha256 values in
source-identity.json before reusing this build/test evidence.
